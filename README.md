# DawudEngine


This is based on the SMFL Game Development Book by Jan Haller

So far I have implemented chapter 7.

The game is a Vertical Scrolling Shooter. The aim is to reach the end of the level without dying.

## Known Bugs

- Pressing a key to open app counts input twice. For example if you press enter when on the home screen it will register the input twice and put you in the game instantly. So please avoid pressing enter on the home screen.
